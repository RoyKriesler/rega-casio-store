# watch-store — "רגע" curated watch shop (demo)

Portfolio project for Roy. Hebrew, RTL, light retail-style e-commerce demo of a (fictional) curated retailer: Casio, Tissot, Hamilton, Seiko, Citizen, Orient, Bulova, Timex, Oris, plus own-label straps. Design refs Roy liked (2026-10-14): Rolex, Tudor, Hamilton official sites and Chrono24: centered logo header, search, family cards with "discover" links, size + price on cards. Goal (Roy, 2026-10-13): eventually make it a real store, only watches Roy finds worthy and cool. His taste refs: Tissot PRX, Emboss dress watches, Ted Martin chronographs, Hamilton Khaki Field on NATO. NOT a real store: no real payments, no card fields, checkout is a mock that creates a fake order number.

Trademark rules (decided 2026-10-13): store name is "רגע", never brand logos in site chrome; add a model only when the photo is identifiable (photographer description names it); footer states no affiliation with any maker. Emboss/Ted Martin not added: no licensed photos. Selling Tissot/Hamilton new with warranty needs authorized-dealer status with the Israeli importer. Avoid unverifiable factual claims in copy.

## Stack
- Next.js 15 App Router, TypeScript, Tailwind v4 (tokens in `src/app/globals.css` `@theme`).
- Fonts via `next/font/google` (Hebrew subset where available).
- Node is at `~/.local/node/bin` and is NOT on PATH: prefix commands with `export PATH=$HOME/.local/node/bin:$PATH`.
- Deploy target: Vercel. Repo: GitHub account RoyKriesler.

## Data
- Brand rule (Roy, 2026-10-15): every brand on the site has at least 10 watches; a brand that cannot reach 10 is removed (Grand Seiko, Mido, Certina, Rado dropped 2026-10-15).
- Catalog: `src/data/products.ts` (static) plus `src/data/products-expansion.ts` (generated by `scripts/import_expansion.py` from `research/catalog-expansion.json`; edit the script, not the TS), ~127 watches + 3 straps. `condition: "vintage"` = discontinued, sold pre-owned, gold badge and a note on the product page. `brand` per product, collections sport/field/dress/vintage(digital)/gshock/straps. Shop filters: `c` collection, `b` brand, `p` price band, `s` sort, `q` search (brand EN/HE, name, model).
- Brand pages `src/data/brands.ts` + `/brands/[slug]` (founding facts only). Guides `src/data/guides.ts` + `/guides/[slug]`.
- Prices in ILS. `priceSource: "market"` = seen on zap.co.il 2026-10-13 (sources in `research/prices-2026-10-13.md`); others are estimates and the product page says "מחיר משוער". Never present an estimate as a market price.
- Commons photos: id is `<upload.wikimedia.org url>#w=<original width>`; `photoUrl` serves a cached Commons thumbnail at a standard step (330/500/960/1280) and components pass `unoptimized={isCommons(id)}` (the Commons CDN returns 429 on bursts of originals). Credit is "Author · license" (CC BY / BY-SA).
- Images: hotlinked from `images.unsplash.com` (Unsplash License, free), real Casio photos. Photographer credit per photo, listed on `/credits`. A photo must show the brand it is listed under.
- Round SVG trig coordinates to 2 decimals or hydration breaks.
- Variants: `Product.variants` (color + photo); cart lines keyed by `slug::variant`.
- Cart: React context + localStorage (wrapped in try/catch), `src/lib/cart.tsx`.

## Conventions
- `<html lang="he" dir="rtl">`. Use logical Tailwind utilities (`ps-`, `pe-`, `ms-`, `me-`, `start-`, `end-`), never `pl-/pr-/left-/right-` for layout.
- Look (2026-10-14 evening, Roy loved panerai.com + a NOMOS "films" card): dark Panerai-style site. Black `#0a0a0a`, bold Heebo headlines, white square CTAs, full-screen video hero, full-bleed lifestyle image, horizontal collections accordion (`CollectionsAccordion.tsx`), Nomos-style rounded light film cards with hover preview + modal player (`FilmCards.tsx`), pinned scroll story (`PinnedStory.tsx`). Text over video/images must keep >= 4.5:1 worst-frame contrast.
- Theme (2026-10-14, Roy chose): champagne only, light ivory + muted gold, Frank Ruhl serif headlines. Tokens in `globals.css` `:root`. The theme switcher and `/themes` page were removed at his request. Components must use tokens (paper/ink/line/...), never hard `bg-black`/`text-white`, except over photos/video.
- Hero stills: generated images zoom with CSS keyframes `kenburnsA/B` (smooth). Never bake zoom into video with ffmpeg zoompan: it steps per pixel and shakes (Roy noticed).
- Header (2026-10-14 night, Roy disliked the old one): fixed black bar, hides on scroll down; menu button opens a full-screen menu with a hover image preview; search slides down. `<main>` has `pt-[72px]`, home hero uses `-mt-[72px]`.
- Hero (2026-10-14, Roy: "the best so far"): full-screen `AsciiReveal` of the gears image; the real photo shows through a spotlight under the cursor, drifting on its own when idle or on touch. `HeroPlaylist` (crossfading clips + CSS-zoom stills, random order per visit) now lives in the "בתנועה" section further down.
- Motion layer: Lenis smooth scroll, `Reveal.tsx` (SplitHeading word reveal, FadeIn, MaskReveal), `Marquee.tsx`, `Tilt.tsx` on product cards, `ScrubWatch.tsx` (scroll turns the hands). All respect prefers-reduced-motion. Hero headline uses CSS-only animation so it never depends on hydration.
- `/lab`: 12 live effect demos from an Instagram list Roy sent (particles, split-flap, wireframe 3D, blueprint, holographic, neon, kinetic type, glass, ASCII, halftone, liquid, gradient mesh). Roy picks by number which go into the site.
- Generated art: `art/gen.sh` (mflux FLUX.2 klein 4B, local, free) -> `art/raw/*.png`; `art/export.sh` -> `public/art/*.jpg` and Ken Burns clips `public/video/film-*.mp4`. Atmosphere only: never generate a picture that stands in for a real product listing. Prompts end with "no text, no logo".
- Fonts: Heebo (display, bold), Assistant body, IBM Plex Mono for model numbers (Latin only, never for Hebrew labels).
- No emoji as icons; inline SVG only.
- Respect `prefers-reduced-motion`.
